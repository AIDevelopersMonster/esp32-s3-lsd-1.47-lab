# ESP32-S3 vs ESP-WROOM-32

## Кратко

Сравнивать корректнее **ESP32-S3** с классическим **ESP32**, который используется в модуле **ESP-WROOM-32**. ESP-WROOM-32 — это не отдельный процессор, а готовый радиомодуль на базе ESP32 с Flash, кварцем и антенной.

Для новых проектов с дисплеем, USB, DSP/AI и более тяжёлым интерфейсом ESP32-S3 обычно предпочтительнее. Классический ESP32 в ESP-WROOM-32 остаётся полезным там, где важны Bluetooth Classic, встроенные DAC или Ethernet MAC.

## Сравнение

| Параметр | ESP32-S3 | ESP32 в ESP-WROOM-32 |
|---|---:|---:|
| CPU | 2× Xtensa LX7 | 2× Xtensa LX6 |
| Максимальная частота | 240 МГц | 240 МГц |
| CoreMark, 2 ядра @ 240 МГц | 1329.92 | 1079.96 |
| Относительная CPU-производительность по CoreMark | примерно +23.1% | базовый уровень |
| SIMD / векторные инструкции | 128-битные SIMD-инструкции | нет сопоставимого SIMD-блока |
| FPU | single precision | single precision |
| Встроенная SRAM | 512 КБ | 520 КБ |
| Wi‑Fi | 2.4 ГГц 802.11 b/g/n | 2.4 ГГц 802.11 b/g/n |
| Bluetooth | Bluetooth LE 5 | Bluetooth 4.2 BR/EDR + BLE |
| Bluetooth Classic | нет | есть |
| USB OTG | есть | нет |
| USB Serial/JTAG | есть | нет |
| LCD interface | есть | нет специализированного LCD-интерфейса такого класса |
| Camera interface | 8–16 бит DVP | нет сопоставимого специализированного интерфейса |
| DAC | нет встроенного DAC | 2× 8-бит DAC |
| Ethernet MAC | нет | есть |

## Производительность CPU

Оба семейства могут работать на частоте до 240 МГц и имеют два ядра Xtensa, но архитектуры разные:

- ESP32-S3 — Xtensa LX7;
- классический ESP32 — Xtensa LX6.

По официальным данным Espressif:

- **ESP32-S3:** 1329.92 CoreMark при двух ядрах 240 МГц;
- **ESP32:** 1079.96 CoreMark при двух ядрах 240 МГц.

Это даёт ESP32-S3 преимущество примерно **23.1%** в этом синтетическом CPU-тесте при одинаковой максимальной частоте.

Важно: CoreMark не описывает все реальные нагрузки. В задачах, способных использовать SIMD, преимущество ESP32-S3 может быть заметно выше.

## SIMD и DSP/AI

Одно из ключевых отличий ESP32-S3 — **128-битная шина данных и специальные SIMD-инструкции**. Espressif указывает поддержку 128-битных векторных операций, включая сложение, вычитание, умножение, сдвиги, сравнения и другие операции.

Это особенно полезно для:

- DSP;
- обработки изображений;
- некоторых задач машинного обучения;
- обработки массивов данных;
- аудио и сигналов.

Поэтому ESP32-S3 нельзя оценивать только как «тот же ESP32 на 240 МГц, но немного быстрее».

## USB

ESP32-S3 имеет встроенные:

- **Full-Speed USB OTG**;
- **USB Serial/JTAG controller**.

Это позволяет создавать USB-устройства без отдельного USB-UART моста: HID, CDC, MIDI и другие классы USB.

У классического ESP32 из ESP-WROOM-32 встроенного USB OTG нет.

## Bluetooth

Здесь у старого ESP32 есть важное преимущество.

### ESP32-S3

- Bluetooth LE 5;
- Bluetooth Mesh;
- без Bluetooth Classic.

### ESP32 / ESP-WROOM-32

- Bluetooth 4.2 BR/EDR;
- Bluetooth LE;
- поддерживается Bluetooth Classic.

Если проекту нужен именно Bluetooth Classic, классический ESP32 может оказаться более подходящим.

## Аналоговые возможности

Классический ESP32 имеет **два встроенных 8-битных DAC**. У ESP32-S3 встроенного DAC нет.

Поэтому проекты, использующие простое аналоговое формирование сигнала непосредственно средствами MCU, иногда удобнее реализовывать на классическом ESP32.

## Ethernet

У классического ESP32 есть аппаратный **Ethernet MAC** с DMA. Для проводного Ethernet требуется внешний PHY, но MAC присутствует в самом SoC.

У ESP32-S3 такого Ethernet MAC нет.

## Почему ESP32-S3 хорошо подходит для Waveshare ESP32-S3-LCD-1.47

Для платы Waveshare ESP32-S3-LCD-1.47 особенности S3 особенно полезны:

- встроенный LCD-интерфейс и высокая производительность для графики;
- USB OTG и USB Serial/JTAG;
- SIMD для тяжёлых вычислений;
- возможность работы с внешней/встроенной PSRAM в зависимости от варианта S3;
- удобная база для LVGL, графических интерфейсов и компактных приборов.

Практические направления:

1. LVGL и графические панели;
2. Wi‑Fi/BLE приборы;
3. USB HID/CDC устройства;
4. портативные диагностические инструменты;
5. DSP и экспериментальные TinyML-задачи;
6. отображение телеметрии, датчиков и сетевой информации.

## Когда выбрать что

### Выбирать ESP32-S3, если нужны

- дисплей и сложный GUI;
- USB OTG;
- USB Serial/JTAG;
- SIMD / DSP / TinyML;
- более высокая CPU-производительность;
- современный BLE 5.

### Выбирать классический ESP32 / ESP-WROOM-32, если нужны

- Bluetooth Classic;
- два встроенных DAC;
- аппаратный Ethernet MAC;
- совместимость с большим количеством старых ESP32-проектов и плат.

## Вывод

**ESP32-S3 — более современная вычислительная платформа для дисплеев, USB, DSP/AI и сложных пользовательских интерфейсов.**

**ESP32 в ESP-WROOM-32 — более старое, но всё ещё очень полезное решение, особенно когда нужны Bluetooth Classic, DAC или Ethernet MAC.**

Для Waveshare ESP32-S3-LCD-1.47 выбор ESP32-S3 хорошо соответствует назначению платы: графика, USB, беспроводная связь и компактные автономные приложения.
