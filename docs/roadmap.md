# Roadmap

## v0.1 - board bring-up

- LCD test
- Flash and PSRAM information
- microSD detection
- Wi-Fi scanner
- BOOT-button page switching
- RGB status indication
- PlatformIO CI build

## v0.2 - reusable board support

- Separate display, storage and input classes
- LVGL 9 example
- PNG/JPEG viewer from microSD
- USB mass-storage experiment
- Serial terminal page

## v0.3 - practical instruments

- Wi-Fi signal monitor
- MQTT/HTTP status panel
- YouTube or server statistics display
- ESP-NOW remote control
- Sensor and I2C diagnostic tools

## v1.0

- Hardware-tested pin map
- Reproducible release firmware
- English and Russian documentation
- Case / enclosure files
