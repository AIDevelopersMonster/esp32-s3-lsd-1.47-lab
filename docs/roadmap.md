# Roadmap

## v0.1 - board bring-up

- LCD test
- Flash and PSRAM information
- microSD detection
- Wi-Fi scanner
- BOOT-button page switching
- RGB status indication
- PlatformIO CI build

## v0.2 - reusable board support

- Separate display, storage and input classes
- LVGL 9 example
- PNG/JPEG viewer from microSD
- USB mass-storage experiment
- Serial terminal page

## v0.3 - practical instruments

- Wi-Fi signal monitor
- MQTT/HTTP status panel
- YouTube or server statistics display
- ESP-NOW remote control
- Sensor and I2C diagnostic tools

## Интересное / разобрать

- [ESPWebTool / esptool.spacehuhn.com](https://esptool.spacehuhn.com/) — разобрать как браузерный инструмент для работы с ESP через Web Serial/WebUSB: возможности прошивки, чтения/записи Flash, поддерживаемые чипы, формат manifest/config и возможность применения или интеграции в наш workflow для ESP32-S3-LCD-1.47.
