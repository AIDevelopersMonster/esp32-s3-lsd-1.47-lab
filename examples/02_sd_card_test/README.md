# 02 — microSD / SD_MMC test (Arduino IDE)

Этот пример проверяет встроенный слот **microSD/TF** на плате
**Waveshare ESP32-S3-LCD-1.47** через `SD_MMC` в 4-битном режиме.

Главное отличие от предыдущего LCD-теста: результат этого примера **не выводится
на дисплей платы**. Всё, что происходит с картой, нужно смотреть в **Serial
Monitor Arduino IDE** на скорости **115200 baud**.

Скетч работает только на чтение:

- определяет наличие карты;
- определяет тип карты;
- показывает её размер;
- открывает корневой каталог;
- показывает имена файлов и папок;
- ничего не создаёт, не удаляет и не форматирует.

## Видео-подтверждение

Реальный запуск этого примера на физической плате:

**[YouTube Shorts — ESP32-S3-LCD-1.47 microSD / SD_MMC test](https://youtube.com/shorts/eVARX5pUqp4)**

# Коротко: что нужно сделать

1. Возьмите microSD/TF-карту **не больше 16 ГБ**.
2. Желательно отформатируйте её в **FAT32**.
3. Для проверки запишите на карту один-два файла, например `test.txt`.
4. Вставьте карту в слот платы.
5. Откройте в Arduino IDE файл:

```text
examples/02_sd_card_test/02_sd_card_test.ino
```

6. Выберите плату **ESP32S3 Dev Module**.
7. Выберите COM-порт платы.
8. Нажмите **Verify** и убедитесь, что скетч компилируется.
9. Нажмите **Upload**.
10. После загрузки откройте **Serial Monitor**.
11. Установите скорость **115200 baud**.
12. Нажмите RESET на плате, если вывод уже прошёл до открытия Serial Monitor.
13. В Serial Monitor должен появиться размер карты, список файлов и строка:

```text
SD card test OK
```

Если эта строка появилась — базовый тест microSD пройден.

---

# 1. Какую карту использовать

Для текущего baseline-теста этого проекта используйте:

```text
microSD / TF <= 16 ГБ
FAT32
```

Карты больше 16 ГБ пока не считаются подтверждённой конфигурацией для этого
примера.

## Почему пока не больше 16 ГБ

На конкретном экземпляре платы с заводской прошивкой Waveshare наблюдалось:

| Карта | Результат на заводской прошивке |
|---|---|
| 16 ГБ | карта определяется, но на экране показывается размер `0` |
| 32 ГБ | на LCD появляется рябь / графические помехи |

Это пока только экспериментальное наблюдение для конкретной платы и заводской
прошивки. Оно **не доказывает**, что ESP32-S3 аппаратно не умеет работать с
картами 32 ГБ и больше.

Именно поэтому этот отдельный скетч нужен для проверки SD независимо от
заводского интерфейса и LCD.

---

# 2. Подготовьте microSD-карту

Для первого теста лучше использовать карту, на которой нет важных данных.

Рекомендуемый порядок:

1. Вставьте карту в компьютер.
2. Убедитесь, что её объём не больше 16 ГБ.
3. При необходимости отформатируйте её в FAT32.
4. Создайте в корне карты простой текстовый файл:

```text
test.txt
```

Например, внутри можно написать:

```text
ESP32-S3 SD test
```

5. Можно дополнительно создать папку:

```text
TESTDIR
```

6. Безопасно извлеките карту из компьютера.
7. Вставьте её в слот microSD/TF на ESP32-S3-LCD-1.47.

Наличие `test.txt` и `TESTDIR` необязательно для работы SD, но так сразу видно,
что скетч действительно читает каталог карты.

---

# 3. Что нужно установить в Arduino IDE

Дополнительные библиотеки через Library Manager для этого примера **не нужны**.

Скетч использует:

```cpp
#include <Arduino.h>
#include <SD_MMC.h>
```

Обе библиотеки входят в пакет ESP32 Arduino Core:

```text
esp32 by Espressif Systems
```

Для проекта используйте версию **3.0.2 или новее**.

## Как проверить ESP32 package

В Arduino IDE 2.x откройте **Boards Manager** на левой панели или:

```text
Tools -> Board -> Boards Manager...
```

В поиске введите:

```text
esp32
```

Должен быть установлен:

```text
esp32 by Espressif Systems
```

Если рядом указано `Installed`, пакет уже есть.

Если Arduino IDE при компиляции пишет:

```text
SD_MMC.h: No such file or directory
```

то обычно проблема не в отдельной библиотеке, а в том, что ESP32 board package
не установлен или выбрана не ESP32-плата.

---

# 4. Откройте скетч

В Arduino IDE откройте:

```text
examples/02_sd_card_test/02_sd_card_test.ino
```

Это можно сделать через:

```text
File -> Open...
```

или просто открыть `.ino` двойным щелчком.

---

# 5. Выберите плату

В Arduino IDE выберите:

```text
Tools -> Board -> esp32 -> ESP32S3 Dev Module
```

Либо нажмите селектор платы в верхней части Arduino IDE и найдите:

```text
ESP32S3 Dev Module
```

---

# 6. Выберите COM-порт

Подключите ESP32-S3-LCD-1.47 к компьютеру.

В Arduino IDE откройте:

```text
Tools -> Port
```

и выберите COM-порт, соответствующий плате.

На тестовом компьютере это был, например:

```text
COM16
```

У вас номер может быть другим.

Если непонятно, какой COM-порт относится к плате, отключите её, посмотрите список
портов, затем подключите снова — новый появившийся порт и есть нужный.

---

# 7. Настройки Arduino IDE

Рекомендуемые параметры:

| Параметр | Значение |
|---|---|
| Board | **ESP32S3 Dev Module** |
| Port | COM-порт вашей платы |
| USB Mode | **Hardware CDC and JTAG** |
| USB CDC On Boot | **Enabled** |
| CPU Frequency | **240 MHz** |
| Flash Size | **16MB (128Mb)** |
| PSRAM | **OPI PSRAM** |
| Flash Mode | **QIO 80MHz** |
| Partition Scheme | схема для **16 MB Flash** |
| Core Debug Level | **None** |
| Erase All Flash Before Sketch Upload | **Disabled** |

Названия некоторых пунктов могут немного отличаться между версиями ESP32 core.

---

# 8. Сначала нажмите Verify

Нажмите кнопку с галочкой **Verify** в верхней части Arduino IDE.

Ожидаемый результат: компиляция завершается без ошибок.

Если компиляция прошла, это означает, что:

- ESP32 core установлен;
- `SD_MMC.h` найден;
- выбранная ESP32-S3 плата поддерживается;
- скетч готов к загрузке.

---

# 9. Загрузите скетч в плату

Нажмите **Upload**.

Arduino IDE скомпилирует и запишет программу во Flash ESP32-S3.

При нормальной загрузке в нижней панели Arduino IDE появятся сообщения esptool,
а в конце — успешное завершение загрузки.

Если загрузка не начинается автоматически:

1. Зажмите **BOOT**.
2. Кратко нажмите и отпустите **RESET**.
3. Отпустите **BOOT**.
4. Снова нажмите **Upload**.
5. После успешной загрузки при необходимости один раз нажмите **RESET**.

---

# 10. Где смотреть результат

Это самый важный момент: **результат теста смотрим не на LCD, а в Serial
Monitor Arduino IDE**.

Открыть Serial Monitor можно кнопкой в правом верхнем углу Arduino IDE или через
соответствующий пункт интерфейса Arduino IDE 2.x.

В нижней части окна откроется панель Serial Monitor.

Установите скорость:

```text
115200
```

Если Serial Monitor был открыт уже после выполнения скетча, нажмите **RESET** на
плате. Скетч выполнится ещё раз и вы увидите сообщения с самого начала.

---

# 11. Что должно появиться в Serial Monitor

При исправной карте вывод должен быть примерно таким:

```text
ESP32-S3-LCD-1.47 microSD test
Mode: READ ONLY / SD_MMC 4-bit
Card type: SDHC/SDXC
Card size: 15193 MiB
Root directory:
       test.txt  18 bytes
[DIR] TESTDIR  0 bytes
SD card test OK
No files were changed.
```

Число `15193 MiB` здесь только пример. Реальное число зависит от конкретной
карты.

Главные признаки успешного теста:

```text
Card type: ...
Card size: ... MiB
Root directory:
...
SD card test OK
```

Если вы специально положили на карту `test.txt`, его имя должно быть видно в
списке.

---

# 12. Почему 16 ГБ не обязательно будут показаны как 16384 MiB

Маркировка производителя карты в GB и двоичный расчёт объёма в MiB — не одно и
то же. Кроме того, часть ёмкости может уходить на служебную разметку.

Поэтому карта с надписью `16 GB` вполне может отображаться как значение заметно
меньше 16384 MiB.

Для этого теста важно, что размер определяется стабильно и каталог читается.

---

# 13. Что получится, если карта пустая

Если карта успешно читается, но в корне нет файлов, будет примерно:

```text
ESP32-S3-LCD-1.47 microSD test
Mode: READ ONLY / SD_MMC 4-bit
Card type: SDHC/SDXC
Card size: ... MiB
Root directory:
(root directory is empty)
SD card test OK
No files were changed.
```

Это тоже успешный результат.

---

# 14. Если карта не вставлена

Serial Monitor покажет ошибку наподобие:

```text
ERROR: Card mount failed
```

или:

```text
ERROR: No card inserted
```

Проверьте карту и нажмите RESET.

---

# 15. Если появляется `Card mount failed`

Проверьте по порядку:

1. Карта вставлена в слот полностью.
2. Используется microSD/TF не больше 16 ГБ.
3. Карта отформатирована в FAT32.
4. Выбрана **ESP32S3 Dev Module**.
5. Выбран правильный COM-порт.
6. Загружен именно `02_sd_card_test.ino`.
7. GPIO в скетче не изменялись.
8. После установки/замены карты нажимался RESET.
9. Попробуйте другую карту до 16 ГБ.

---

# 16. Что будет с картой больше 16 ГБ

Скетч определяет reported capacity после mount.

Если карта больше текущего baseline, в Serial Monitor появится:

```text
WARNING: Card is larger than the current <=16 GB project test range.
Use a <=16 GB microSD/TF card for the baseline hardware test.
```

После этого скетч прекращает дальнейший просмотр каталога.

Это сделано специально, чтобы не считать непроверенную конфигурацию успешно
подтверждённой.

---

# 17. Распиновка microSD/TF

Встроенный слот подключён так:

| Сигнал SD | GPIO |
|---|---:|
| CMD | 15 |
| CLK | 14 |
| D0 | 16 |
| D1 | 18 |
| D2 | 17 |
| D3 | 21 |

Пример использует **SD_MMC в 4-битном режиме**.

---

# 18. Почему этот тест ничего не выводит на LCD

Это сделано намеренно.

Заводская прошивка одновременно работает с LCD и microSD, поэтому при проблеме
с 32 ГБ картой мы увидели рябь, но по одному этому симптому нельзя понять, где
именно причина.

`02_sd_card_test.ino` полностью отделяет SD-тест от дисплея и выводит результат
только в Serial Monitor. Так проверяются отдельно:

- физический слот карты;
- линии SD_MMC;
- mount файловой системы;
- размер карты;
- чтение каталога.

Если этот тест проходит, следующим этапом уже можно проверять совместную работу
SD + LCD.

---

# 19. Критерий успешного теста

Тест считается пройденным, если в Serial Monitor:

1. нет `Card mount failed`;
2. отображается тип карты;
3. отображается ненулевой размер карты;
4. читается корневой каталог;
5. в конце появляется:

```text
SD card test OK
No files were changed.
```

После этого результат можно считать hardware-verified для конкретной карты и
конкретного экземпляра платы.
