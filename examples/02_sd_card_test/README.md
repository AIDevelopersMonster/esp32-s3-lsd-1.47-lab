# 02 — microSD / SD_MMC test (Arduino IDE)

Пример проверяет встроенный слот **microSD/TF** на плате
**Waveshare ESP32-S3-LCD-1.47** через периферию ESP32-S3 `SD_MMC` в 4-битном
режиме.

Скетч выполняет только чтение:

- инициализирует SD_MMC;
- определяет тип карты;
- показывает её размер в Serial Monitor;
- открывает корневой каталог;
- выводит список файлов и папок;
- ничего не создаёт, не форматирует и не удаляет.

## Важное ограничение по карте

Для этого проекта в качестве базовой тестовой карты используйте **microSD/TF не
больше 16 ГБ**.

Рекомендуется формат **FAT32**.

Это ограничение зафиксировано как практический безопасный диапазон для текущего
экземпляра платы и текущего набора тестов. Оно не означает, что сам ESP32-S3 или
контроллер SD_MMC принципиально не способны работать с более крупными картами.
Карты большего объёма пока считаются **непроверенными для этой платы в рамках
проекта**.

## Наблюдения на заводской прошивке

На реальном экземпляре платы с исходной заводской прошивкой Waveshare были
получены следующие результаты:

| Карта | Что показывает заводская прошивка |
|---|---|
| 16 ГБ | карта определяется, но на экране отображается размер `0` |
| 32 ГБ | на дисплее появляется рябь / графические помехи |

Важно: эти наблюдения относятся именно к **конкретной плате и её заводской
прошивке**. Пока не установлено, вызваны ли они ограничением самой factory demo,
форматом файловой системы, особенностями инициализации SD, совместным
использованием GPIO/памяти или другой причиной.

Поэтому в этом примере мы не выдаём симптом за доказанную аппаратную
несовместимость. Для воспроизводимого baseline-теста используем карту до 16 ГБ и
проверяем её собственным минимальным скетчем отдельно от заводского интерфейса.

Перед экспериментами рекомендуется уже иметь сохранённый заводской образ Flash:

## Что нужно установить

Для этого примера **дополнительные библиотеки через Library Manager не нужны**.

Скетч использует:

```cpp
#include <Arduino.h>
#include <SD_MMC.h>
```

Оба заголовка входят в пакет:

```text
esp32 by Espressif Systems
```

Для платы **ESP32-S3-LCD-1.47** используйте ESP32 Arduino core версии **3.0.2 или
новее**.

## Как проверить наличие SD_MMC в Arduino IDE

Если пакет ESP32 установлен правильно, `SD_MMC.h` уже доступен.

Проверить можно тремя способами.

### Через Boards Manager

Откройте:

```text
Tools -> Board -> Boards Manager...
```

или Boards Manager на левой панели Arduino IDE 2.x.

В поиске введите:

```text
esp32
```

Должен быть установлен:

```text
esp32 by Espressif Systems
```

### Через Examples

После установки ESP32 core в меню:

```text
File -> Examples
```

обычно доступны примеры работы с SD/SD_MMC для ESP32.

### Через Verify

Откройте:

```text
examples/02_sd_card_test/02_sd_card_test.ino
```

и нажмите **Verify**.

Если Arduino IDE сообщает:

```text
SD_MMC.h: No such file or directory
```

то проблема обычно не в отдельной библиотеке, а в отсутствующем или неправильно
выбранном ESP32 board package.

## Настройки Arduino IDE

Выберите:

```text
Tools -> Board -> esp32 -> ESP32S3 Dev Module
```

Рекомендуемые параметры:

| Параметр | Значение |
|---|---|
| Board | **ESP32S3 Dev Module** |
| Port | COM-порт подключённой платы |
| USB Mode | **Hardware CDC and JTAG** |
| USB CDC On Boot | **Enabled** |
| CPU Frequency | **240 MHz** |
| Flash Size | **16MB (128Mb)** |
| PSRAM | **OPI PSRAM** |
| Flash Mode | **QIO 80MHz** |
| Partition Scheme | схема для **16 MB Flash** |
| Core Debug Level | **None** для обычного теста |
| Erase All Flash Before Sketch Upload | **Disabled** без специальной необходимости |

После загрузки откройте **Serial Monitor** на скорости:

```text
115200 baud
```

## Распиновка встроенного microSD/TF слота

Слот на этой плате подключён к SD_MMC так:

| Сигнал SD | GPIO |
|---|---:|
| CMD | 15 |
| CLK | 14 |
| D0 | 16 |
| D1 | 18 |
| D2 | 17 |
| D3 | 21 |

Пример использует именно **4-битный SD_MMC режим**, то есть задействованы все
линии `D0...D3`.

## Подготовка карты

Для первого теста рекомендуется:

1. Взять microSD/TF **до 16 ГБ включительно**.
2. Сделать резервную копию содержимого карты, если оно важно.
3. Отформатировать карту в **FAT32**.
4. Для наглядности положить в корень несколько обычных файлов и папку.
5. Вставить карту в слот до включения/RESET платы.

Скетч карту не форматирует и содержимое не меняет.

## Ожидаемый вывод

При успешной работе Serial Monitor должен показать примерно:

```text
ESP32-S3-LCD-1.47 microSD test
Mode: READ ONLY / SD_MMC 4-bit
Card type: SDHC/SDXC
Card size: ... MiB
Root directory:
       example.txt  1234 bytes
[DIR]  photos  0 bytes
SD card test OK
No files were changed.
```

Реальный размер в MiB обычно не совпадает буквально с маркетинговой надписью на
карте в ГБ — это нормально из-за разных способов подсчёта объёма.

## Что делает ограничение в скетче

После успешного mount скетч проверяет reported capacity.

Если размер больше текущего project baseline в 16 ГБ, он выводит предупреждение
и прекращает дальнейший просмотр каталога:

```text
WARNING: Card is larger than the current <=16 GB project test range.
Use a <=16 GB microSD/TF card for the baseline hardware test.
```

Это сделано не потому, что чтение большой карты доказано опасным для ESP32-S3, а
чтобы не смешивать подтверждённую конфигурацию с пока непроверенными картами.

## Если получаете `Card mount failed`

Проверьте:

1. Карта вставлена полностью.
2. Используется microSD не больше 16 ГБ для baseline-теста.
3. Карта отформатирована в FAT32.
4. Выбрана **ESP32S3 Dev Module**.
5. Используется правильный COM-порт.
6. Загружен именно этот пример.
7. GPIO в скетче не изменены.
8. После замены карты выполнен RESET.

Если одна карта не работает, а другая того же объёма работает, это может быть
проблемой конкретной карты, разметки разделов или файловой системы.

## Почему мы тестируем SD отдельно от LCD

Заводская прошивка одновременно использует дисплей и microSD, поэтому симптом на
экране сам по себе не говорит, какой именно компонент дал сбой.

Этот пример намеренно не инициализирует ST7789 вообще. Результат выводится только
через Serial Monitor. Так можно независимо проверить:

- физический слот;
- SD_MMC GPIO;
- mount файловой системы;
- определение размера;
- чтение каталога.

После этого уже можно отдельно исследовать совместную работу LCD + SD.
