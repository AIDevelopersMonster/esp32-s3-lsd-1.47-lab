# 01 — Display test (ST7789, Arduino IDE)

Минимальный тест встроенного дисплея **ST7789 172×320** на плате
**Waveshare ESP32-S3-LCD-1.47**.

Скетч специально сделан простым: он не использует LVGL, microSD, Wi-Fi или
RGB-светодиод. Его задача — проверить, что Arduino IDE, ESP32-S3, SPI и LCD
работают вместе, а распиновка дисплея выбрана правильно.

После успешной загрузки на экране должны появиться:

- `ESP32-S3` белым цветом;
- `LCD 1.47` голубым цветом;
- зелёная рамка;
- надпись `Display test OK` жёлтым цветом.

## Перед первой прошивкой

Если на плате ещё сохранена заводская прошивка Waveshare, сначала рекомендуется
сделать её полный backup. В этом репозитории для этого есть отдельная инструкция
и read-only PowerShell-скрипт:

- [../../docs/firmware-backup.md](../../docs/firmware-backup.md)
- [../../tools/backup-factory.ps1](../../tools/backup-factory.ps1)

После сохранения заводского образа можно переходить к Arduino-экспериментам.

## Что нужно установить

### 1. ESP32 board package

В Arduino IDE должен быть установлен пакет:

```text
esp32 by Espressif Systems
```

Для **ESP32-S3-LCD-1.47** Waveshare указывает версию **3.0.2 или новее**.

В Arduino IDE 2.x:

1. Откройте **Boards Manager** на левой панели Arduino IDE.
2. В поиске введите `esp32`.
3. Найдите **esp32 by Espressif Systems**.
4. Нажмите **Install** или **Update**.
5. Убедитесь, что установлена версия `3.0.2` или новее.

Альтернативный путь через меню может выглядеть как:

```text
Tools -> Board -> Boards Manager...
```

## Библиотеки для этого примера

Скетч подключает:

```cpp
#include <SPI.h>
#include <Adafruit_GFX.h>
#include <Adafruit_ST7789.h>
```

Нужны следующие компоненты:

| Include в скетче | Что установить | Где берётся |
|---|---|---|
| `SPI.h` | отдельно устанавливать не нужно | входит в ESP32 Arduino core |
| `Adafruit_GFX.h` | **Adafruit GFX Library** | Arduino Library Manager |
| `Adafruit_ST7789.h` | **Adafruit ST7735 and ST7789 Library** | Arduino Library Manager |

При установке Adafruit-библиотек Arduino IDE может также предложить установить
их зависимости, в частности **Adafruit BusIO**. Соглашайтесь на установку всех
предлагаемых зависимостей.

Для этого минимального LCD-теста **не нужны** LVGL, PNGdec и Adafruit NeoPixel.
Они могут понадобиться другим примерам проекта, но данный скетч от них не
зависит.

## Как установить библиотеки в Arduino IDE

В Arduino IDE 2.x откройте **Library Manager** кнопкой на левой панели либо через:

```text
Sketch -> Include Library -> Manage Libraries...
```

Затем установите по очереди:

### Adafruit GFX Library

В поле поиска введите:

```text
Adafruit GFX Library
```

Выберите библиотеку **Adafruit GFX Library** от Adafruit и нажмите **Install**.
Если Arduino IDE предложит установить зависимости — подтвердите.

### Adafruit ST7735 and ST7789 Library

В поле поиска введите:

```text
ST7789
```

Выберите:

```text
Adafruit ST7735 and ST7789 Library
```

и нажмите **Install**.

## Как проверить, что библиотеки уже установлены

Есть несколько простых способов.

### Способ 1 — Library Manager

Откройте Library Manager и снова найдите:

```text
Adafruit GFX Library
Adafruit ST7735 and ST7789 Library
```

У установленной библиотеки Arduino IDE показывает статус **Installed** и
установленную версию вместо обычной кнопки установки.

### Способ 2 — Examples

После установки в меню:

```text
File -> Examples
```

должны появиться разделы библиотек Adafruit. Для ST7789 обычно доступен пример
типа `graphicstest_st7789` внутри **Adafruit ST7735 and ST7789 Library**.

### Способ 3 — компиляция этого скетча

Откройте:

```text
examples/01_display_test/01_display_test.ino
```

и нажмите **Verify / Compile**.

Если библиотека отсутствует, компилятор обычно сообщает, какой заголовочный файл
не найден. Например:

```text
Adafruit_GFX.h: No such file or directory
```

означает, что нужно установить **Adafruit GFX Library**.

```text
Adafruit_ST7789.h: No such file or directory
```

означает, что нужно установить **Adafruit ST7735 and ST7789 Library**.

Если не находится `SPI.h`, проблема обычно не в отдельной библиотеке: проверьте,
что установлен ESP32 board package и выбрана ESP32-S3 плата.

## Что выбрать в Arduino IDE

Подключите ESP32-S3-LCD-1.47 к компьютеру и откройте:

```text
Tools -> Board -> esp32 -> ESP32S3 Dev Module
```

Либо в Arduino IDE 2.x нажмите селектор платы сверху и выберите
**Select Other Board and Port**, затем найдите:

```text
ESP32S3 Dev Module
```

После этого выберите COM-порт, который появился при подключении платы.
Например:

```text
COM16
```

Номер COM-порта у каждого компьютера может быть другим.

### Рекомендуемые параметры Tools

Для этого проекта используются следующие настройки:

| Параметр Arduino IDE | Значение |
|---|---|
| Board | **ESP32S3 Dev Module** |
| Port | COM-порт подключённой платы |
| USB Mode | **Hardware CDC and JTAG** |
| USB CDC On Boot | **Enabled** |
| CPU Frequency | **240MHz (WiFi)** / стандартные 240 MHz |
| Flash Size | **16MB (128Mb)** |
| PSRAM | **OPI PSRAM** |
| Flash Mode | **QIO 80MHz** |
| Partition Scheme | схема для **16 MB Flash** |
| Core Debug Level | **None** для обычного теста |
| Erase All Flash Before Sketch Upload | **Disabled** без специальной необходимости |

Названия отдельных пунктов могут немного отличаться между версиями пакета
`esp32`, но принцип остаётся тем же: ESP32-S3, 16 MB Flash, OPI PSRAM и встроенный
USB CDC/JTAG.

Полная памятка Arduino IDE для проекта находится в
[../../docs/arduino-ide.md](../../docs/arduino-ide.md).

## Распиновка LCD

Скетч использует аппаратную распиновку именно **ESP32-S3-LCD-1.47**:

| LCD | ESP32-S3 GPIO |
|---|---:|
| MOSI | 45 |
| SCLK | 40 |
| CS | 42 |
| DC | 41 |
| RESET | 39 |
| Backlight | 48 |

MISO для этого теста не нужен, потому что скетч только передаёт данные в LCD.

## Открытие и проверка скетча

Откройте файл:

```text
examples/01_display_test/01_display_test.ino
```

Arduino IDE должна открыть его как обычный sketch.

Сначала нажмите кнопку **Verify** (галочка). Если компиляция завершилась без
ошибок, значит:

- ESP32 board package найден;
- выбранная плата поддерживается;
- `SPI.h` найден;
- Adafruit GFX найден;
- драйвер ST7789 найден;
- сам скетч синтаксически собирается.

## Загрузка в плату

После успешной проверки нажмите **Upload**.

Если автоматический вход в загрузчик не сработал:

1. Зажмите **BOOT**.
2. Кратко нажмите и отпустите **RESET**.
3. Отпустите **BOOT**.
4. Снова нажмите **Upload** в Arduino IDE.
5. После успешной загрузки при необходимости один раз нажмите **RESET**.

Для первого теста не требуется Serial Monitor: результат отображается прямо на
LCD.

## Что делает скетч

Последовательность запуска простая:

1. Гасит подсветку, чтобы инициализация дисплея не была видна как случайные
   данные на экране.
2. Настраивает SPI на физических выводах платы.
3. Инициализирует ST7789 как дисплей `172×320`.
4. Очищает экран чёрным цветом.
5. Включает подсветку.
6. Выводит несколько строк и прямоугольник разных цветов.
7. `loop()` остаётся пустым: изображение после отрисовки хранится в самом LCD.

## Если экран остаётся чёрным

Проверьте последовательно:

1. Загружен ли скетч без ошибок.
2. Выбрана ли именно **ESP32S3 Dev Module**.
3. Выбран ли правильный COM-порт.
4. Установлены ли обе Adafruit-библиотеки.
5. Используется ли плата **ESP32-S3-LCD-1.47**, а не `1.47B` и не Touch-версия.
6. Не изменены ли GPIO в скетче.
7. Нажмите RESET после загрузки.

Если компиляция проходит, но экран работает с неправильной ориентацией, можно
экспериментировать с:

```cpp
tft.setRotation(0);
```

значениями `0`, `1`, `2`, `3`. Для базовой проверки этого примера используется
`0`.
