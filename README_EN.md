# ESP32-S3-LCD-1.47 Lab

A clean starter and educational repository for the Waveshare
**ESP32-S3-LCD-1.47** board with USB-A, 1.47-inch ST7789 display, microSD slot,
16 MB Flash and 8 MB PSRAM.

The main firmware provides:

- system and memory information;
- microSD detection;
- Wi-Fi scanning;
- BOOT-button page switching;
- onboard RGB status indication;
- reproducible PlatformIO build and GitHub Actions workflow.

See [README.md](README.md) for the primary Russian documentation.

> Status: initial bring-up version. The code is based on the official Waveshare
> pin map and established ST7789 library usage, but the first physical-board
> validation and screenshots are still required.
